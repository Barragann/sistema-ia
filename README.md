# Sistema de IA

Proyecto de practica para la materia Arquitectura de Sistemas de Inteligencia Artificial.

## Descripcion

Mini proyecto que simula el desarrollo inicial de un sistema de IA (modelo, inferencia y API) para practicar el flujo de trabajo con Git y GitHub.

## Objetivo

Aprender a controlar versiones, usar ramas, Pull Requests y colaboracion sobre un proyecto de IA.

## Componentes

- Modelo
- Inferencia
- Configuracion
- Documentacion

## Tecnologias

- Python
- Git
- GitHub
